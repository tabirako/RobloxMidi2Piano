# RobloxMidi2Piano
This script needs python libraries **rtmidi** and **keyboard** to work

Install these libraries with 
```bat
pip install python-rtmidi
```
and 
```bat
pip install keyboard
```
or by downloading them from [rtmidi](https://pypi.org/project/python-rtmidi/) and [keyboard](https://pypi.org/project/keyboard) manually
